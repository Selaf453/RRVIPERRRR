# Островок 3.1 (Rust + Tauri)

Один файл `Ostrovok.exe`. Python не нужен. Использует WebView2, он уже есть в Windows 10 и 11.
Конфиг тот же, что у Python-версии (`%APPDATA%\Ostrovok\config.json`): домашка, дневник и Telegram переезжают сами.
Пароль дневника совместим со старым (проверено тестом на то же значение хеша).

## Как получить exe через GitHub
1. Загрузи в репозиторий всё содержимое этой папки, включая `.github`
   (если она не загрузилась: Add file → Create new file → `.github/workflows/build.yml` и вставь текст).
2. Вкладка Actions → Build Ostrovok.exe → Run workflow. Сборка 10–15 минут.
3. Внизу запуска в Artifacts скачай `Ostrovok-exe`, внутри `Ostrovok.exe`.
4. Закрой старый Островок (трей → Выход) и запусти новый.

## Что есть
Остров с 33 настроениями, танцами и репликами; уведомления про флешки, интернет, раскладку, Caps Lock,
скриншоты, батарею, перерывы; домашка из Telegram и напоминания раз в час; дневник с паролем;
режим учёбы с плейлистом; игровой режим и нагрузка в игре; тексты песен; озвучка; отсчёт до ЕГЭ;
заметки (Ctrl+Alt+N); режим фокуса (Ctrl+Alt+F). ПКМ по острову: потыкать.

## Чего нет по сравнению с Python-версией
Анализ ударов трека (танец идёт по таймеру, а не по басу), снижение громкости плеера в режиме учёбы,
расписание уроков и редактор приложений с поиском. Данные этих разделов в конфиге не удаляются.
