# Островок для Android

Остров с глазами, звуками, вибрацией на «пора отдохнуть» и списком домашки.
Напоминания работают, пока приложение открыто на экране.

## Как получить .apk через GitHub
1. Создай на github.com новый репозиторий (кнопка New, имя любое).
2. Нажми «uploading an existing file» и перетащи ВСЁ содержимое этой папки,
   включая скрытую папку `.github`. Нажми Commit changes.
   Если `.github` не загрузилась: Add file → Create new file, назови
   `.github/workflows/build-apk.yml` и вставь туда содержимое одноимённого файла.
3. Вкладка Actions → Build APK → Run workflow. Подожди 5–10 минут.
4. Открой завершённый запуск, внизу в Artifacts скачай `Ostrovok-apk`.
   Распакуй zip, внутри `app-debug.apk`.
5. Кинь файл на телефон и открой его. Android попросит разрешить установку из
   этого источника, разреши.

## Если сборка упала
Открой красный запуск, скопируй текст ошибки и пришли мне.
